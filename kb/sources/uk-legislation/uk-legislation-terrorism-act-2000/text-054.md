7 (1) Before issuing a code of practice the Secretary of State shall—

(a) publish a draft code, (b) consider any representations made to him about the draft, and (c) if he thinks it appropriate, modify the draft in the light of any representations made to him.

(2) The Secretary of State shall lay a draft of the code before Parliament.

(3) When the Secretary of State has laid a draft code before Parliament he may bring it

into operation by order.

(4) This paragraph has effect in relation to the issue of a revised code as it has effect in
