## 6 Conclusions

- **descriptive / context**: The paper presents Graph Feature Preprocessor (GFP), a software library for fast feature extraction from dynamically changing transaction graphs, which uses an in-memory dynamic multigraph representation and fine-grained parallel subgraph enumeration algorithms. (p. 8)[^original]  
  <sub>anchor: "We presented Graph Feature Preprocessor (GFP), a software library for fast feature extraction from dynamically changing transaction graphs."</sub>
- **descriptive / finding or result**: GFP lets the graph ML pipeline operate in a streaming manner with low per-batch latency and higher throughput than the GNN baselines in the experiments, making it suitable for real-time processing. (p. 8)[^original]  
  <sub>anchor: "GFP enables our graph ML pipeline to operate in a streaming manner with low per-batch latency and higher throughput"</sub>
- **descriptive / finding or result**: Graph-based features generated by GFP can significantly improve the accuracy of gradient-boosting-based machine learning models. (p. 8)[^original]  
  <sub>anchor: "We have also shown that the graph-based features generated by GFP can significantly improve the accuracy of gradient-boostingbased machine learning models."</sub>
- **descriptive / finding or result**: Graph-based features improve the minority class F1 score of gradient-boosting models by up to 46% on the synthetic AML datasets. (p. 8)[^original]  
  <sub>anchor: "The graph-based features improve the minority class F1 score of gradient-boosting-based machine learning models by up to 46% for the synthetic AML datasets"</sub>
- **descriptive / finding or result**: Graph-based features improve the minority class F1 score of gradient-boosting models by up to 35% on a real-world phishing detection dataset extracted from Ethereum. (p. 8)[^original]  
  <sub>anchor: "and by up to 35% for a real-world phishing detection dataset extracted from Ethereum."</sub>
- **descriptive / finding or result**: The solution achieves up to a 36% higher F1 score than GNN baselines for the AML task. (p. 8)[^original]  
  <sub>anchor: "Furthermore, we show that our solution achieves up to a 36% higher F1 score than GNN baselines for the AML task."</sub>
- **descriptive / finding or result**: The graph ML pipeline achieves up to a 24% higher minority-class F1 score than the GIN+EU baseline, which has a similar architecture to LaundroGraph, a GNN designed for anti-money laundering. (p. 8)[^original]  
  <sub>anchor: "our graph ML pipeline achieves up to a 24% higher minority-class F1 score compared to the GIN+EU baseline"</sub>
- **descriptive / context**: The GFP library's application scope is not limited to money laundering detection; the paper notes that a cycle in a graph can indicate tax avoidance, circular trading, and credit card fraud, so GFP could also help detect these fraud types. (p. 8)[^original]  
  <sub>anchor: "The application scope of our GFP library is not limited to money laundering detection."</sub>
- **descriptive / limitation**: Reliance on pre-defined subgraph patterns, such as cycles, is a drawback of the library; the authors plan to add subgraph matching using user-defined patterns as future work. (p. 8)[^original]  
  <sub>anchor: "the reliance on pre-defined subgraph patterns, such as cycles, is one drawback of this library"</sub>
- **descriptive / recommendation**: The authors plan to add feature extraction for additional subgraph patterns, such as cliques and bicliques, which could enable detection of close-knit communities and stacked money laundering patterns. (p. 9)[^original]  
  <sub>anchor: "we plan to add support for feature extraction based on additional subgraph patterns, such as cliques [9] and bicliques [59]."</sub>
