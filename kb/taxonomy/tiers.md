# Source tiers

- **Tier 1**: law / regulator
- **Tier 2**: intergovernmental body / standard setter
- **Tier 3**: academic
- **Tier 4**: industry / bank
- **Tier 5**: consulting
- **Tier 6**: vendor
- **Tier 7**: other

Tier describes the issuer; `normative_force` describes the document. A tier 1 issuer can publish a consultation (hypothesis).
